# Configurar QEMU

Se crea una máquina virtual con QEMU para simular los nodos de la red VPN, instalando Ubuntu Server como sistema operativo base.

Crear almacenamiento

```bash
qemu-img create -f qcow2 peer1.qcow2 20G
```

Ejecutar la instalacion de ubuntu

```bash
qemu-system-x86_64 \                                                             
    -m 2048 \
    -cdrom ubuntu-24.04.4-live-server-amd64.iso \
    -hda peer1.qcow2 \
    -boot d \
    -enable-kvm \
    -vga virtio \
    -cpu host
```

Ejecutar la maquina virtual

```bash
qemu-system-x86_64 -m 2048 -hda ~/work/vpn/peer1.qcow2 -enable-kvm -vga virtio -cpu host
```

Ejecutar con la nueva red bridge

```bash
sudo qemu-system-x86_64 \
  -m 2G \
  -drive file=peer1.qcow2 \
  -netdev tap,id=net0,ifname=vmtap0,script=no,downscript=no \
  -device virtio-net-pci,netdev=net0
```


Conectar por ssh

```bash
ssh peer1@localhost -p 2222
```

# Configurar bridge

Identifica el nombre de tu interfaz de red física (ej. `eth0` o `enp3s0`):

```bash
ip link
```

```bash
ls /etc/netplan/
```

Edita tu configuración de Netplan

```bash
sudo nano /etc/netplan/01-netcfg.yaml
```

Aplica los cambios

```bash
sudo netplan apply
```
