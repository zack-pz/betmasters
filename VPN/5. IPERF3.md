Se usa iperf3 para medir el ancho de banda real del túnel WireGuard y verificar que la red tiene el rendimiento suficiente para la distribución de trabajo entre nodos.

Inicia iperf3 en modo servidor 
```bash
iperf3 -s
```

Prueba estándar de 10 segundos (TCP) 
```bash
iperf3 -c 10.10.10.1
```

Prueba en dirección inversa — mide el ancho de banda de bajada desde el hub
```bash
iperf3 -c 10.10.10.1 -R
```

Prueba con 4 flujos paralelos — simula carga concurrente de múltiples workers
```bash
iperf3 -c 10.10.10.1 -P 4
```

Prueba UDP con ancho de banda objetivo de 100 Mbps — detecta pérdida de paquetes y jitter
```bash
iperf3 -c 10.10.10.1 -u -b 100M
```
