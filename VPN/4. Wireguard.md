Se instala y configura WireGuard para crear una red VPN hub-and-spoke donde el coordinador actúa como hub (`10.10.10.1`) y cada worker se conecta como spoke con su propia clave.

```bash
# Instala WireGuard (interfaz VPN), UFW (firewall) e iperf3 (pruebas de red)
sudo apt update
sudo apt install wireguard
sudo apt install ufw
sudo apt install iperf3
```

Genera la clave privada del nodo y deriva su clave pública correspondiente
```bash
umask 077

wg genkey | tee privatekey | wg pubkey > publickey
```

Obtiene la IP pública del nodo
```bash
curl -4 icanhazip.com
```

Abre el archivo de configuración de la interfaz WireGuard (wg0)
```bash
sudo nano /etc/wireguard/wg0.conf
```

```bash
[Interface]
PrivateKey = 4[PEER_PRIVATEKEY]  # Clave privada de este nodo
Address = 10.10.10.2/24          # IP del nodo dentro de la VPN
DNS = 1.1.1.1                    # Servidor DNS a usar en el túnel
ListenPort = 51820               # Puerto UDP en el que escucha WireGuard

[Peer]
PublicKey = [HUB_PUBLICKEY]      # Clave pública del coordinador (hub)
Endpoint = [IP_HUB]:51820        # IP pública y puerto del coordinador
AllowedIPs = 10.10.10.0/24       # Rango de IPs enrutadas por el túnel
PersistentKeepalive = 25         # Envía un ping cada 25s para mantener la conexión activa
```

Levanta la interfaz WireGuard y establece el túnel VPN
```bash
sudo wg-quick up wg0
```

Muestra la configuración activa de la interfaz (peers, claves, puertos)
```bash
sudo wg showconf wg0
```

Verifica conectividad con el coordinador (hub) a través del túnel
```bash
ping 10.10.10.1
```

Detiene y elimina la interfaz WireGuard
```bash
sudo wg-quick down wg0
```
