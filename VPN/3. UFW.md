Se configura UFW para abrir únicamente los puertos necesarios: SSH para administración remota, WireGuard para la VPN y el puerto de la aplicación Rust.

Permitir SSH (Crítico):
```bash
sudo ufw allow 22/tcp
```

Permitir WireGuard:
```bash
sudo ufw allow 51820/udp
```

Permitir tu app rust
```bash
sudo ufw allow 8080/tcp
```

Habilitar el Firewall:
```bash
sudo ufw enable
```

Verificar el Estado:
```bash
sudo ufw status numbered
```

Habilitar Frowarding
```bash
sudo nano /etc/ufw/sysctl.conf
```
